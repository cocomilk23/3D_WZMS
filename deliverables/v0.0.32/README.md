# v0.0.32 体育馆外景

工程：`models/campus/WZMS_Campus_v032.blend`。新增集合 280—288，检查相机 129—132，继承 v031 操场与此前校园。

依据体育馆外景 119232392、操场 119232357 及航拍制作白色分格外墙、青绿色高窗、横向通风百叶、后退入口与门窗框、宽台阶、小方砖前场、绿色铺装条带、树池、榕树、灯具和落水管。道路接入南田路已经预留的体育馆支路。

建筑保持可编辑外壳，屋面、屋面接缝和可见桁架分开制作。遮挡的屋顶形状、背面窗格、整体跨度和相对位置属于图像估计。正门玻璃门保持关闭，步行检查止于门前，**本版不含体育馆一、二层完整内景**。

航拍审查发现的弧形屋面与端墙漏缝、侧后墙窗台下方缺口已补齐，再次保存、重开、检查并渲染。两条新增通路共 899 个几何采样点通过检查，旧场景未发生意外变更。

本版为未测绘校准的初版，用户验收与 UE 漫游、碰撞和性能验证尚待进行。网页不更新。下一版制作完整篮球场并整合西侧运动区。

连接航拍中，体育馆东侧支路两旁仍有未补齐的场地边角；道路自身连续可通行，这些边角纳入 v033 运动区整合填补。
