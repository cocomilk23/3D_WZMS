# v0.0.3 南大门网页交互预览

本次交付：`web-preview/` 本地网站、GLB 模型、四张原始 Blender 渲染对照图、启动服务和导出脚本。

## 使用入口

本机服务运行期间访问 http://127.0.0.1:8766/ 。同一电脑上的浏览器或 Codex 浏览面板均可使用。其他设备不能直接使用这个地址。

支持鼠标旋转、缩放、平移，四个预设视角，自动旋转、网格查看、全屏以及静态渲染对照。手机宽度布局已检查；实际手机设备访问和性能尚未验证。

## 转换与质量

保留南大门样板的几何结构，合并 1,976 个网格/曲线对象以减少绘制批次；浏览器加载后为 20 个材质网格、664,788 个三角形。GLB 约 12.7 MB，使用 Draco 压缩，未主动做几何减面。原始 `.blend` 未被导出流程改写。

修正了对象合并时不同 UV 层名称导致墙面贴图丢失的问题。网页中重建了铺装材质，灯光与 Blender 不完全相同；右上角“渲染对照”保留原始渲染画面。

这仍是首版样板的观察器，不是已经接入 UE 的碰撞漫游，也不代表模型尺寸和浮雕已经精确还原。

## 核验

浏览器中检查模型加载、校名贴图、四视角、拖动、缩放、恢复视角、自动旋转、网格、全屏和渲染图加载。保留桌面和窄屏截图，以及 `browser_validation.json`、`export_validation.json`。

本版本仅启动本地服务，未发布公网网站。服务重启方式见 `web-preview/README.md`。
