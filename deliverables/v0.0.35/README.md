# v0.0.35 四块网球场与中间隔墙

在原两块场地旁增加同朝向的两块，组成两组并列球场。保留蓝色围网、灰紫色比赛区、绿色外围、白色标线和真实网格球网。中间改为蓝色实体隔墙，带压顶和白色练习线，两端可通行。

数量与“两组并列、中间有墙”来自用户明确反馈。采用既有 23.77×10.97 米设计比例，场地位置、28 米隔墙长度和外围绿化仍为估算。

旧版估算的水南小房、岸地和栈桥占到了新增球场范围。本版把小房与岸边细节整体向北移 16 米，重接荷屿至北侧球场入口的栈桥及小房支路。荷屿主体和原网球场西入口保留；沿墙旧花箱移到新外侧边界。变更对象逐一列在 replacement_scope.json 中。

检查图覆盖四场航拍、隔墙端部、地面、俯视和荷屿连接。保存后重新打开，核对四个独立场地中心、隔墙实体，以及原入口、墙端通道和水南连接的可通行性；结果见本目录 JSON。经过审图的交付由 delivery_validation.json 固定工程与图片哈希。
