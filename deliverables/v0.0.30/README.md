# v0.0.30 西门

工程：`models/campus/WZMS_Campus_v030.blend`。在 v029 校园上新增集合 260—268，检查相机 121—124。

依据西门 119232350 与道司前路 119232375 制作灰砖主拱门、两侧通道及八个低拱廊、三个圆窗、圆窗放射砖、曲线山墙与校名、石栏杆、门柱陶色纹样、打开的铁门、花盆、石板院落、层状松树和景墙，并连接既有西门预留支路。原有校园对象保留。

审查图后加深并区分砖墙色差，补合拱廊与主门接缝，补齐院落背后与现有校园之间的连续地面；后者为估计的场地补全。新增两条步行检查路线共 708 个采样点通过，保存后重新打开核验。

这是可编辑、未测绘校准的初版。参考中的铁门关闭，本版设为打开以便未来行走；无法辨读的历史浮雕只保留简化面板与框线，未虚构历史文字。隐蔽背面、庭院尺度和相对坐标仍待校准，用户验收待进行。未更新网页，未作 UE 漫游验证。
