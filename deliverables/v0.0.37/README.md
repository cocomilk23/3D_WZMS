# v0.0.37 数学馆室内

以 119232397—404 的前言、苏步青、谷超豪、群星璀璨、二层、放映厅、休息区和教室为依据，建立双层展览动线。包含蓝色展墙、原图展板、低玻璃展柜、通高门厅、米黄色吊灯、白色楼梯及玻璃扶手、木地板、弧形木座放映区、沙发休息角和传统木课桌教室。

先前 v019 的窄翼房和圆形房间是未完成室内的外景估算。本版将这组壳体替换为可容纳展厅的 U 形布局，保留白色入口墙、圆洞花格和外围通道。北侧退出九山路已有通路。该平面、楼层连接、房间相对位置和尺度属于推定，不能视为馆方真实平面图。

历史文字与照片采用打包的本地原始全景图片作为展面参考，没有补写人物事迹。图片展面保留原来的透视，是模型中的参考纹理，不是逐字重排的出版级展板。家具、柜体、楼梯和灯具均为可编辑几何。

六张检查图覆盖主要空间。保存后重开核对地面、楼梯、净高及九山路衔接；结果见本目录报告，审图后由 delivery_validation.json 固定哈希。未涉及无素材的额外房间，也未更新网页或进行 UE 游戏内验收。
