# v0.0.33 篮球场与西侧运动区整合

工程：`models/campus/WZMS_Campus_v033.blend`。新增集合 290—298，检查相机 133—138，继承 v032 体育馆以及之前的校园。

根据篮球场点位 119232358、南田路 119232379 与两个航拍点位制作红绿场地，保留照片里的梯形罚球区。场地包含六块球场、十二套绿色悬臂篮球架、玻璃篮板、橙色篮圈、悬挂菱形绳网、标线、围网、开口、座椅和照明。球架、篮板、篮圈和网均为可编辑网格。六场的排列、方位和校园位置是依据图片安排的估算；篮圈采用 3.05 米设计高度，不代表完成实测校准。

本版替换 v008 的中山路侧球场占位集合 `52_Zhongshan_Middle_Court_Edge` 和 v009 的北侧延伸占位集合 `65_North_Court_Visible_Edge`，具体替换名单写入 `replacement_scope.json`。通过北侧支路接南田路，东侧开口接中山路，南侧步道接江口路。最后两张航拍分别检查西门—操场—体育馆—篮球场和全校园的组合关系。

同时填补 v032 航拍中体育馆东侧支路两旁的剩余地面边角，作为可编辑、明确标注的估计地块，不改变已交付的体育馆模型。

整合检查发现东南角围网与已有江口路通路相交，已缩短该处围网并留出入口；南侧新步道绕过原有文化景墙东端，保持既有道路和景墙坐标。审图后清理北侧残留的蓝色占位地面及旧围网，加深场地绿色并减少篮板磨砂感。修正后重新生成工程并进行完整路线复查。

## 检查与验收

保存后重新打开文件，再对 v017—v033 登记的 47 条路线检查实际几何的地面连续、台阶、净高和身体宽度。检查结果以 `geometry_validation.json` 为准；这不代替 UE 的运行时碰撞和游戏内行走验收。前序模型对象的几何、UV、材质槽和位置变化保存在 `preservation_validation.json`，明确允许替换的占位物除外。南门背面墙另有完整保留核验。

最终工程的 20,092 个路径采样点、47 条路线全部通过；145 个替换对象均来自明确登记的两组旧球场集合，前序对象无意外变更。具体结果保存在本目录 JSON 报告中。

交付目录附六张 1600×1000 审查图，覆盖地面、篮架细节和航拍。完成审图后由 `delivery_validation.json` 固定工程及图片哈希。四场景的版本、远端标签及 LFS 文件可用 `scripts/verify_sports_deliveries.ps1` 复查。
