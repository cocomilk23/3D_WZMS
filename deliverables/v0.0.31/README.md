# v0.0.31 操场与蓝白看台

工程：`models/campus/WZMS_Campus_v031.blend`。新增集合 270—278，相机 125—128，保留 v030 西门与此前校园。

依据操场 119232357、南田路 119232378/379 及航拍制作红色八道跑道、偏黄天然草坪、蓝白座椅、两侧阶梯看台、中央裁判室、钢构雨棚、场边照明和跳高垫。入口接到已有南田路 1/3 号门，跑道、草地和看台入口设置实际几何通路检查。

草坪材质取自 119232357 向下全景中的可读草地区域，通过材质坐标避开全景拼接补丁，再叠加短草几何。原始全景面完整打包进工程，未修改原始素材文件。

看台由座椅、固定支架、台阶、栏杆、雨棚立柱、斜撑及屋面分别组成；发现首级台阶相对场边地面过高后补了铺装平台。南侧补齐西门与原校园之间剩余连接地块。只替换明确标注的旧运动区地面占位对象，明细见 `replacement_scope.json`。

内侧测量线采用常见 400 米跑道比例，36.5 米内缘半径、1.22 米道宽作为建模约束；这些是设计输入，**不是温州中学现场测量结论**。草坪未强行加入参考中无法确认的清晰足球标线。实际场地尺度、周边退界与看台结构仍需校准。

本版为可编辑初版，用户验收、UE 漫游和运行性能验收待进行；不更新网页。下一版为体育馆外景。
