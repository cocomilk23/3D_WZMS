# v0.0.38 校史馆室内

根据 119232405—418 制作首层展厅：红色入口地毯、前言、温中百年、英奇匡国、历任校长、名师荟萃、孙诒让、题词及照片墙。包含黑色条形吊顶、轨道射灯、房屋轮廓展框、木质玻璃陈列柜、中央展岛和校园沙盘展台。

十四个点位是对展览区域的多个视角，不当作十四个独立房间。本版在既有西翼内安排连通环线。先前曲面外景玻璃中与西翼内部重叠的估算段被明确替换，其余建筑保持。室内相对位置、陈列尺寸和柜数为推定；没有复现未知的二层和邻楼室内。

人物介绍、照片和书法使用打包的原始全景作为参考展面，不自行编写历史文字。展台上的小比例校园体块是可编辑示意模型，并非对历史沙盘逐栋测绘。原图纹理仍有拍摄透视，后续可替换为更清晰的正视资料。

五张检查图和保存后重新打开的通行、前序对象检查用于技术核验，报告保存在本目录。delivery_validation.json 记录已审阅版本的文件哈希；用户验收和 UE 运行时测试另行进行。本版不更新网页。
