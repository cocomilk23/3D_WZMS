# v0.0.29 南田路与西侧文化区整合

工程：models/campus/WZMS_Campus_v029.blend。新增集合 250—258，检查相机 115—120；包含此前版本场景及本批榕屿、籀园学堂、校友风采区域。

依据南田路 119232376—379 制作沥青路面、虚线、榕树行道树、白刷树干、路缘与排水、绿色运动场围网、可见 1/3 号入口、停车牌，以及步青广场方向的绿色玻璃过街入口。连接道司前路、校友风采、步青广场和江口路，并预留后续运动区支路。

新增步青广场连接处仅裁剪挡路的两件旧绿化网格，原座椅、垃圾桶向南平移四米。对象明细记录在 landscape_adjustments.json 与 replacement_scope.json。整合版重新检查 v017 起登记的步行路径，并独立核验按用户要求暂不修改的南门背面墙。

航拍及地面审查后补齐南田路至围网、江口路路口以及门厅北侧的连续地面，避免分批地块之间出现悬空缝隙。这些连接地块的边界仍为估计，不作为操场尺寸或绿化设计的实测依据。

运动场侧现仅有道路边界与入口；操场、体育馆和篮球场本体尚待后续制作。全景未提供测绘尺寸，本版仍是可编辑、未严格校准的初版，用户验收待进行。几何路线检查不替代 UE 运行时碰撞和漫游测试。本批网页未更新。
