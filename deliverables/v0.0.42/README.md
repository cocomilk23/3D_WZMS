# v0.0.42 南侧航拍布局与岸线校正

本版以已建教学楼为固定参照，校正南大门、广场、四块网球场、荷塘、荷屿和水南路小建筑之间的相对位置。它解决 v041 球场过于偏东、南侧景观各自拼接而间距不协调的问题，保留上一版确认的四场排列与朝向。

[完整校园工程](../../models/campus/WZMS_Campus_v042.blend)

## 修改范围

- 四块球场连同地基、围栏、球网和隔墙平移；比赛区尺寸不变。中心改为 (22,-31)、(40,-31)、(58,-31)、(76,-31)，长边仍朝向教学楼。
- 南门整组移至新位置，右侧伸缩门收拢以留出步行入口，广场铺地重新衔接教学楼前步道。座椅、灯具和树木按新布局重新放置，不因广场加长而拉长。
- 原独立小椭圆池替换为较宽的荷塘，与东侧水面接通。调整荷屿和水南路小建筑位置，重建桥、球场入口和岸边步道，并补齐南侧场地下方的基础与岸线。
- 教学楼及其北侧校园保留；v040 已有构件与材质精修保留。南门背面校歌墙随门区整体平移，原网格、UV、材质和打包图片内容保留。

## 依据与误差

使用本地完整航拍 `119232347/l.jpg`，并参考用户提供的航拍裁图和网球场地面图。利用一块球场可见白线和名义比赛区尺寸建立近似地面映射，以教学楼门洞地面作为现有模型参照；随后将推算的位置取整并协调连接处。

手工取点、全景投影和遮挡会影响结果，远离球场的点位对取点误差尤其敏感。上述坐标属于图像估算和设计协调，不是实测坐标，不能据此宣称已经严格 1:1 校准。原始取点、映射矩阵和采用的位置记录在 [layout_reference_analysis.json](layout_reference_analysis.json)。
