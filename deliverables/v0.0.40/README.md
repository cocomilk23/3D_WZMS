# v0.0.40 本部整体写实深化与网球场转向

在 v039 上推进整校现有场景的构件与材质精修。本轮包括 578 处空心窗洞、1,178 组窗部细节、290 台外机、3,823 个构件倒角、18 处屋面压顶、1,452 个看台座椅的座面及靠背、112 个食堂凹面圆凳和 228 种材质；具体记录见 refinement_manifest.json。十四张正式检查图已逐张审阅，工程和图片由 delivery_validation.json 封存，逐图记录见 visual_review_notes.json。

## 网球场纠正

根据用户本轮明确纠正，并复查本部航拍 119232347/L 和地面 119232359：四块球场连同球网、边线和隔墙整体旋转 90°。场区沿中山路方向纵向延伸，南北两组、每组左右两块，球场长轴为 Y。中心为 (74,8)、(92,8)、(74,44)、(92,44)，隔墙横向位于 Y=25.9。四场数量保留，篮球场的八块及上次修正朝向保留。

原版本估算的荷屿位置与新北侧球场相交，本版将荷屿可编辑岛体、植物、路径整体向北平移 36 米，并重新连接主路、球场北门及水南设施。改动属于未测绘位置的协调调整，不能当作实测坐标。中间墙两端、球网外侧、北门和桥梁均纳入实际几何通行检查。旧版本及其旧路线报告保持原状。
保留球场南侧地面及东侧、斜岸水面的覆盖范围，将南侧水域合成等高连续面，并补齐荷屿北移后的周边水面；按现有广场和绿地边界封闭两处旧地面空隙，避免连接边界露空。

## 整体精修

- 校园共用窗洞由实心背板改为空心四边窗框，增加密封条、窗扣、连接件和局部褶皱窗帘；窗帘开合是合理推定。
- 空调外机增加实体同心防护网、径向支撑、散热片和安装底脚；既有建筑的框、柱、梁、窗台、檐口和室内家具增加合理倒角，屋顶女儿墙增加压顶。
- 看台座椅替换为有厚度、有弯曲座面和靠背的壳体，共用网格减轻重复资产负担。食堂圆凳改为连续凹面及翻边，去掉原来的叠加圆盘。
- 数学馆沙发补分体坐垫与滚边，柔化布艺边缘并将靠垫调整到坐垫上；传统桌椅增加搁板、围板和曲面椅背；校史馆示意沙盘增加窗列层次，仍然是示意模型。
- 全校园既有石材、灰泥、砖地、涂层、金属、木材、织物、玻璃、水面和叶片统一增加适度的表面细节。木材采用连续纹理，玻璃采用透射与反射，水面使用小尺度波纹，叶片增加色差与透光。保留原有区域配色。
- 日照调整以减少浅色立面的过曝，正式检查图采用 96 次采样；没有以提高渲染设置代替模型修改。

## 范围与验收

这是覆盖整体现有模型的一轮写实深化，不是全校园所有未知房间或实测 1:1 的完成声明。没有增加新疆部，没有重写原始全景图或历史展板文字，南门背面校歌墙按用户要求保持原状。新增窗帘、家具连接及外机细件等是依据可见类型作出的构造推定。

检查包括：保存后重新打开、球场数量与长轴/球网朝向、登记路线、前序对象改动范围、保存材质图变化、原照片材质和南门保留，以及十四个外景/内景检查机位。UE 运行时碰撞、性能和实测尺度仍须另行验收。本版不更新网页。

68 条登记路线、29,891 个采样位置全部通过；构件、水面连续性、改动范围、原照片与南门保留检查通过。植物仍沿用可编辑程序化树形，近景轮廓仍有简化；校史馆斜看展柜的机位反光较强，相关观察已在逐图记录中列明。
