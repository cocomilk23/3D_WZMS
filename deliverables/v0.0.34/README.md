# v0.0.34 篮球场数量与朝向修正

基于用户明确纠正，将 v033 的六场替换为南北四排、东西两列，共八块篮球场；每块长轴相对旧版旋转 90°。保留红绿配色、梯形罚球区和可编辑篮架、篮板、篮圈、绳网。共十六套篮架。

球场采用 28×15 米的设计比例；场间距离、紧凑固定支架和周边排布仍是估算。数量、4×2 排列及旋转要求来自用户，不以模糊航拍充当实测证据。重新检查了本地 119232347、348 航拍和既有 358、379 依据。

扩宽场地时将中山路西步道移入原有树带，调整对应绿化、消防栓和围网，接回步道两端；保持中山路、南田路主路和江口路文化景墙。完整替换名单见 replacement_scope.json。旧 v033 工程与报告保留。

保存后重开检查前序对象和五条通行路线，4,000 个采样点通过；另按实际网格核对八个场地中心、长轴与十六个篮圈。五张检查图含完整俯视布局、航拍、地面、中央通道和东入口，工程与图片经审阅后由 delivery_validation.json 固定哈希。

未更新网页；尚未进行 UE 游戏内碰撞验收。新疆部暂停，网球场修正和本部室内按后续独立版本交付。
