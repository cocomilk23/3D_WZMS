# v0.0.2 南大门三维样板

用户于 2026-09-06 授权：参考覆盖不到的部分可以做适度设计补全，先制作一个完整可检查的场景。为先验证实际产出，本次样板先于全校园体块阶段制作。

## 文件

- `models/south_gate/WZMS_SouthGate_v002.blend`：Blender 5.1.2 场景，单位为米，包含四个对照相机。
- 本目录 `previews/`：从保存后的模型重新打开并渲染的正面、斜侧、航拍和地面细节图。
- `scene_manifest.json`：对象统计、参考点位与估算项。
- `render_validation.json`：模型重新打开、渲染设备、贴图依赖及输出检查。
- `scripts/blender/build_south_gate.py`：可重复生成的建模源文件。

## 本次制作范围

南大门校名墙、入口铺装及盲道、花盆与花卉、两侧伸缩门、门卫房、绿化与树木，以及此视角可见的后方建筑体量。墙体、门体、门卫房、路面、花盆、树木具有真实三维结构，可以切换视角查看。

校名墙采用有厚度的曲面墙体，正面书法和底部浮雕保留原始全景照片的表面细节；文字和浮雕尚未逐个雕刻成精确网格，照片中的原有光影也会保留。该方案适合首轮识别度验证，近距离浮雕质量仍须后续深化。

## 参考与设计边界

主要来源：[南大门全景 119232349](https://www.720yun.com/t/a3akiwphz2w?scene_id=119232349)，并参考南大门广场点位 119232352。

校名墙暂按宽 18 米、高 4.85 米、厚 0.62 米搭建。这些是照片比例估算，尚未得到测绘数据支持，不能视为严格 1:1。模型中的墙背、门卫房隐藏立面、树冠形态和背景建筑纵深属于设计推断。

原全景中的人物、临时宣传展板、外围施工围挡以及完整城市背景尚未复现。门卫房信息牌采用简化图形。当前样板尚未导入 UE，也未交付独立可执行漫游程序。

## 打开与检查

安装 Git LFS 后拉取本版本，使用 Blender 5.1.2 打开场景，选择 `WZMS_SouthGate_Sample`。主参考照片已打包进模型，预览无需连接 720yun。

默认视口采用带贴图的实体显示，便于流畅检查几何和校名。选择相机后按 Ctrl + 小键盘 0 将它设为当前相机，小键盘 0 进入或退出相机视图；鼠标中键可自由旋转视图。若切换材质预览，需要等待着色器准备。原始默认场景保留为独立场景；建模前备份仅保存在本机，不进入版本库。
