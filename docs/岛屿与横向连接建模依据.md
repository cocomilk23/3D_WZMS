## 导航与空间关系

原始热点明确支持：九山路 382 → 桃花岛 419 → 420；382 → 383 → 艺术楼广场 421；421 分别连接艺术楼 422、橘岛 423、校史馆 405；423 → 424。黄色桥后接的是文化建筑共享片区，不能把它只当成校史馆独用入口。

另一条链为九山路 380 → 江口路 384 → 385 → 386 → 南田路 378。竹屿 363 单独与中山路 370 相连。第四个场景包含两条支线，不声称照片证明江口路直接连到竹屿。与现有估算校园坐标衔接的道路弯折、长度、各岛轮廓和建筑间距是建模补全，尚未获得测绘证明。

## 范围和检查限制

本批制作外景。艺术楼 422 内部展画、楼梯和走廊不在本批复原范围；双座小亭用途、雕像身份、植物品种及不可辨文字不编造。已观察到但未精确核准的细节采用可编辑的近似形体。

使用米制估算。几何检查沿指定路线检查地面、0.70 米身体宽度、1.72 米净高、0.20 米台阶上限，并以纵向射线补查细立柱；最终整合重查 v017—v025 所列路线。它不等同于全场无碰撞证明、严格 1:1 校准或 UE 漫游验收。图像核验与用户验收分开记录。
