# 从南大门向北的制作顺序

2026-09-06 用户要求：从南大门向北制作，每完成一个场景执行 Git 管理；不再更新网页预览，由用户自行验收。

## 执行原则

- 先沿南大门广场—中山路—北门这条连续路线向北推进，再按南到北补齐两侧片区。
- 一个制作场景指一块可连续观察的空间，多张全景共同作为参考；不把每张全景机械地当作独立模型。
- 所有片区沿用统一的总场景坐标和尺度规则。相邻道路、岸线、地面标高及建筑边界必须接续；绝对尺寸未核准时保留估算记录。
- 南大门已有样板继续作为入口资产；其中估算背景体块应在相邻片区完成后替换，不能当成准确实景延伸。
- 每场景完成后保存可编辑 Blender 工程、至少一张检查图和简短交付说明，执行 commit、push 并建立可回退的版本标签。说明“已制作”“待用户验收”和剩余问题，不能把自检称为用户验收通过。
- 保留现有网页版本，但后续不再制作网页、导出网页模型或做网页截图验收。
