## 空间与交付

原始导航证明可依次到达 367 → 355 → 368 → 369 → 370 → 371 → 351，371 另接 425 → 426。导航角和可达关系不等同于实测方位、距离与总平面坐标。

步青广场沿既有桥头 x=54、y=134 接入，穿越中央门厅后预留 y=205 的下一个路段。图书馆只先制作广场可见入口边界，整栋图书馆后续深化。下一段道路继续采用相同的局部米制坐标，并检查实际地面接缝和净高。

本批次仍按五个场景分别交付：步青广场、中山路中段、中山路北段、食堂外景、北门。保存工程后重新打开渲染，做地面检查，记录 SHA-256，再独立 commit、push 和 tag。用户验收仍由用户完成。

## 不确定项和补充设计

- 楼深、路宽、层高、地形与绿地的平面边界来自图像估算；无测绘标尺的区域不作严格 1:1 承诺。
- 树冠和重复绿化采用可编辑程序网格及共享实例；形态、间距需要持续对照照片，但不假称每片叶子逐一复原。
- 校徽拼花是由照片重建的网格近似。细小标语、公告与活动展板内容不编造全文，立体雕像面部不宣称达到原像精确肖像程度。
- 北门深色横匾属于可见警务室界面，不能凭印象换成普通校名门楼。疫情期间的棚、宣传板可按参考保留为独立可隐藏的临时物件集合。
- 按用户指示保留南门背面校歌问题。其网格、UV、材质和原始贴图以 v0.0.6 为基准做内容对比，记录在各版 preservation_validation.json。
