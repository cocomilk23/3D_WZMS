# 温州中学校园网页预览

网页 v0.0.16 展示最新 v0.0.15 Blender 整合场景，沿用原南大门页面。原 Blender 工程未修改。

本机访问地址：http://127.0.0.1:8766/ 。仅本机可访问，不是公网分享链接。

Windows 上可以双击 `启动预览.cmd`，保持窗口开启，然后在浏览器打开上面的地址。

首次安装：在本目录运行 `npm ci`。然后在本目录运行 `npm start`，在浏览器打开上述地址。关闭服务后需重新启动。不要通过双击 HTML 的 file 协议打开，模型与模块需要 HTTP 服务。

三维交互：左键拖动旋转、滚轮缩放、右键拖动平移。下方五张卡片或数字键 1–5 进入本轮整合、网球场、道司前路、荷屿、水南路。“前往场景”提供 22 个观察入口，保留原南大门四视角，并覆盖已制作的主线、食堂和北门。右侧按钮依次恢复视角、自动旋转、网格、全屏。触摸屏可单指旋转、双指缩放与平移。

渲染对照：显示对应视角的 Blender 渲染图。网页的实时材质和光照是近似效果，原始渲染图是画面参考。较早的对照图不包含后续新增的周边场景。

网页使用本地 Three.js 0.185.1 与 Draco 解码器，安装依赖后预览不需要访问外部 CDN。约 51 MB 的 GLB 使用 Git LFS，需要先完成 `git lfs pull`。导出合并对象，并将每四片程序化叶片抽取为一片放大的四边形叶片；建筑、桥梁和球场几何保留。程序化材质和玻璃折射采用实时近似效果。编辑请使用原始 Blender 模型。

本版提供当前已建校园的自由观察，不包含人物行走碰撞。尺寸仍待实测校准。旧 `assets/south-gate.glb` 保留，v0.0.3 标签可回退原页面。

重新导出：Blender 后台运行 `scripts/blender/export_campus_web.py`；加载 v015 后运行 `scripts/blender/build_web_catalog.py` 生成相机目录及对照图副本。
