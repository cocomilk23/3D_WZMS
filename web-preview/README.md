# 南大门网页预览

本机访问地址：http://127.0.0.1:8766/ 。仅本机可访问，不是公网分享链接。

Windows 上可以双击 `启动预览.cmd`，保持窗口开启，然后在浏览器打开上面的地址。

首次安装：在本目录运行 `npm ci`。然后在本目录运行 `npm start`，在浏览器打开上述地址。关闭服务后需重新启动。不要通过双击 HTML 的 file 协议打开，模型与模块需要 HTTP 服务。

三维交互：左键拖动旋转、滚轮缩放、右键拖动平移。下方四个按钮或数字键 1–4 切换正面、斜侧、航拍、近景。右侧按钮依次恢复视角、自动旋转、网格、全屏。触摸屏可单指旋转、双指缩放与平移。

渲染对照：显示同一场景对应视角的 Blender 渲染图。网页的实时材质和光照是近似效果，原始渲染图是画面参考。

网页使用本地 Three.js 0.185.1 与 Draco 解码器，安装依赖后预览不需要访问外部 CDN。GLB 使用 Git LFS，需要先完成 `git lfs pull`。导出合并了对象以减少绘制批次，未做几何减面；编辑请使用原始 Blender 模型。

本版只有南大门样板的自由观察功能，不包含人物行走碰撞或全校园漫游。尺寸和浮雕仍沿用 v0.0.2 的已知边界。
