# 校园游览最终交付目标

目标：真实展示已有温州中学本部模型，以第一人称观赏游览为主。保留已经认可的估算尺寸与建筑风格，新疆部不在本轮范围。当前基线为 e5d9ab7 / v0.0.45-ue-campus。

## 必须完成并逐项提供证据

- 连续地形、道路和水岸：处理断层、孔洞、明显拼接；人物不能进入水域，桥梁可正常通过；异常掉落恢复到最近安全位置。
- 行走碰撞：装饰草叶不挡路，地面承托；图书馆内外楼梯完整到达二楼，并检查其余开放楼梯、门口、桥梁、场地连接。
- 开放室内全部开灯且亮度充足；统一室内外曝光过渡，以真实观赏为目标。
- 补校园周边道路、围墙、绿化与必要远景，形成有视觉解释的游览边界。
- 第一人称游览、小地图、全屏地图、地点名称和方向；可选多个起点/快速旅行点；继续游览恢复安全位置；保留可选航拍。
- 主菜单、暂停、操作说明、画质/音量基本设置、退出；默认以校园展示为主，无需战斗或任务系统。
- Windows 独立发布包，含所需资源与运行说明、版本号、校验值。工程、缓存、发布包留在 E 盘。
- 在独立程序中验证：启动、地点选择、存档恢复、连续路线、水域与外边界、室内照明、菜单和退出。记录实际性能与设备，不用少数点位通过代替整体验收。
- 审核发布包素材来源与说明；新增环境估算部分明确记录；创建可分发的完整压缩包。没有平台账号时可交付网盘可上传文件和发布说明，不假称已公开上架。
- 每个完成并验证的阶段 Git 提交并推送；最终标签与发布包对应。

## 顺序

1. 现状诊断、地形水岸和碰撞修复。
2. 照明、环境边界与视觉整合。
3. 游览导航、起点选择、存档与菜单。
4. 打包、独立程序验收、性能优化、交付与发布文档。

## 验证原则

几何采样、实际人物通行、画面检查和独立程序测试各自记录。楼梯必须完整走上楼层并返回，岸边必须实际尝试进入水域；地图/存档必须在运行程序中操作。任何未验证项保持未完成。
