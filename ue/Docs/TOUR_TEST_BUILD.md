# 温州中学 · 校园漫游 — Windows 测试版

本包供项目所有者亲自验收。校园模型采用已认可的估算尺寸，包含本部，不含新疆部；不是测绘成果或学校官方产品。

## 启动

完整解压，运行 `Windows/WZMS.exe`，不要单独移动可执行文件。无需安装 Blender 或 Unreal Engine。若提示缺少 Microsoft Visual C++ 运行库，安装包内 `Windows/Engine/Extras/Redist/en-us/vc_redist.x64.exe` 后重试。

启动后在地图中选择地点，或点击“继续游览”。WASD 行走，鼠标环顾，Shift 加速，空格跳跃，M / Esc 打开地图，Tab 切换航拍，Q / E 下降和上升，R 返回安全位置。建议使用菜单的“保存并退出”。

## 建议优先体验

1. 地点列表和地图标记是否都能传送；图书馆、体育馆、食堂等起点是否正确。
2. 从南大门沿道路进入校园，检查地面接缝、草坪、台阶、桥梁与水岸；人物应无法步行进入水面。
3. 图书馆楼梯上下楼是否顺畅；各室内是否明亮，出入建筑时亮度是否自然。
4. 退出后重新启动，“继续游览”是否恢复位置；画质、声音设置是否保留。

反馈时请注明地点、操作过程、画质档位；有截图更方便定位。独立程序的完整体验验收由用户进行，本包不把编辑器测试视为独立程序验收。

## 当前已知事项

- 部分浅色墙顶存在偏绿的间接光，室内外连续曝光过渡待继续检查。
- RTX 3060 Laptop 6GB 在编辑器中、1701×981 视口、精致画质下，五处固定视角平均约 27–55 FPS，图书馆和体育馆上层是优化重点。这不是独立程序帧率保证。
- 编辑器运行时曾出现一次 GPU 页错误，原因未确认；长时间稳定性尚未通过验收。
- 菜单地图点击名称冲突已在本轮修复；完整鼠标交互需在此测试版验证。

本包版本和源代码提交见 `source-manifest.json`；文件校验值见 `SHA256SUMS.txt`。正式发布仍须结合本次体验反馈完成修整。
