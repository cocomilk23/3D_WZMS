# 温州中学 · 校园漫游 — Windows 交付版

本包为项目所有者的最终收尾交付。校园模型采用已认可的估算尺寸，包含本部，不含新疆部；不是测绘成果或学校官方产品。

## 启动

完整解压，运行 `Windows/WZMS.exe`，不要单独移动可执行文件。无需安装 Blender 或 Unreal Engine。若提示缺少 Microsoft Visual C++ 运行库，安装包内 `Windows/Engine/Extras/Redist/en-us/vc_redist.x64.exe` 后重试。

启动后在地图中选择地点，或点击“继续游览”。WASD 行走，鼠标环顾，Shift 加速，空格跳跃，M / Esc 打开地图，Tab 切换航拍，Q / E 下降和上升，R 返回安全位置。建议使用菜单的“保存并退出”。

## 建议优先体验

本次 0.1.0-final.57 更新步青广场完整校徽、校园重叠表面、两个足球球门，以及篮球场红色间隔与中圈。可直接在地图中选择步青广场、操场、篮球场查看。

1. 地点列表和地图标记是否都能传送；图书馆、体育馆、食堂等起点是否正确。
2. 从南大门沿道路进入校园，检查地面接缝、草坪、台阶、桥梁与水岸；人物应无法步行进入水面。
3. 图书馆楼梯上下楼是否顺畅；各室内是否明亮，出入建筑时亮度是否自然。
4. 退出后重新启动，“继续游览”是否恢复位置；画质、声音设置是否保留。

反馈时请注明地点、操作过程、画质档位；有截图更方便定位。具体检查结果见本包交付清单，编辑器检查与独立程序检查分别记录。

## 当前已知事项

- 场景保留现有艺术化灯光、植被和估算建筑细节，不代表实景测量精度。
- 切换地点后，植被细节、阴影和纹理可能需要短暂加载；水面也会持续变化。
- 性能取决于显卡与画质档位；菜单内可切换画质。此前编辑器帧率不能作为所有电脑的独立程序帧率保证。

本包版本和源代码提交见 `source-manifest.json`；文件校验值见 `SHA256SUMS.txt`。给别人体验时，分享完整 ZIP，不能只发 `WZMS.exe`。
