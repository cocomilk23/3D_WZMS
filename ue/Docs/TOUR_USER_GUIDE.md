# 温州中学 · 校园漫游

本项目以温州中学本部的建筑、景观和校园记忆为主题，提供第一人称自由游览。尺寸根据参考素材估算，缺少参考的周边环境作了适度补充，不是测绘成果。新疆部不包含在本版中。

本文随最终 Windows 发布包交付；当前仍须完成独立程序验收，实际发布版本、包体和配置要求以该版本的验收报告为准。

## 开始游览

下载后完整解压文件夹，再运行其中的 `WZMS.exe`。请保留程序旁的资源目录。首次运行可能需要安装发布包附带的运行库，无需安装 Unreal Engine 或 Blender。

启动后打开校园地图。点击左侧地点名称或右侧地图标记，可以从该地点开始；点击“继续游览”返回上次保存的安全位置。第一次游览从南大门开始。

## 操作

| 操作 | 按键 |
|---|---|
| 行走 | W、A、S、D |
| 环顾四周 | 移动鼠标 |
| 加快行走 | 按住 Shift |
| 跳跃 | 空格 |
| 校园地图、暂停与设置 | M 或 Esc |
| 航拍与返回步行 | Tab |
| 航拍上升、下降 | E、Q |
| 返回最近安全位置 | R |

右上角的小地图显示附近区域、当前位置与朝向。全屏地图始终北向上，包含 24 个游览地点。

水面用于景观展示，人物不能进入。请通过道路和桥梁到达各区域。航拍后再次按 Tab，返回起飞时的步行位置。

## 保存与设置

行走时定期自动保存安全位置，菜单操作及正常退出也会保存。建议使用地图菜单里的“保存并退出”。

画质有“流畅”“均衡”“精致”三个档位；声音按钮依次切换关闭、轻柔、适中和完整。选项会随游览存档保存。
