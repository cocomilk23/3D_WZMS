# 素材来源与重建说明

- 校园参考：用户提供的温州中学 720 云全景及截图，链接 https://www.720yun.com/t/a3akiwphz2w?scene_id=119232347 。详细点位清单保存在工程 reference/reports/scene_inventory.csv。
- 几何与材质：本项目 Blender 校园重建资产，UE 基线来自冻结的 WZMS_Campus_v043.blend；后续地形、水岸、碰撞、环境与照明在 UE 项目中调整。
- 本轮校徽和篮球场参考：用户于 2026-09-10 提供的两张图片；校徽采用原图完整圆形图案。原文件校验值保存在工程 `SourceTextures/Final057/SOURCE.json`，球门为本项目生成的几何。
- 尺寸与周边：尺寸根据参考估算；素材未覆盖的周边建筑、植被及部分细节作了设计补充。灯光为观赏用途估算，不能视为实测参数。
- 展示图片及全景参考的原有权利归各自权利人；提供参考素材和仓库操作权限并不等同于这些图片的独立公开再分发许可。此测试包交给项目所有者验收；公开发行前仍需核对包内图片使用范围。
- 字体：Noto Sans SC，来源 https://github.com/google/fonts/tree/main/ofl/notosanssc ，使用 OFL 许可。项目字体派生记录与许可随包附在 Licenses/NotoSansSC 目录。
- 环境声：本项目生成的轻柔空气声，不是校园现场录音，不含音乐或人声。
- 引擎：使用 Unreal Engine 5.8 打包；本说明不替代引擎本身适用的许可条款。
